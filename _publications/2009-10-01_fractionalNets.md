FractionalNet is a symmetric neural network framework developed to approximate fractional-order derivatives. The network is trained exclusively using integer-order derivative data while learning to predict fractional-order derivatives.

The work investigates network depth, weight initialization, activation functions, and genetic-algorithm-based hyperparameter optimization to improve prediction accuracy and training consistency.
